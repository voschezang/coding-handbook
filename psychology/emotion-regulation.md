## Threat/Drive/Calm System

The being-becoming model can be extended by a third component: threat responses. See [the three Systems Model](https://balancedminds.com/three-system-model/).

<img src="../img/triangle-threat-drive-calm.png" alt="triangle-threat-drive-calm" style="width:36em;" />



| Threat System          | Drive System               | Calm System |
| ---------------------- | -------------------------- | ----------- |
| React to threats       | Progress towards rewards   | Relax       |
| Fight/flight responses | Dopamine seeking behaviour | Peace, rest |
